You are auditing and upgrading **The Wilds** so the game is easier to read, teach, and play quickly in both the **print crafting tree / print materials** and the **digital prototype**.

Your goal is not to redesign the whole game. Your goal is to improve **clarity, iconography, quick-reference usability, and rules readability** across the entire system.

## Mission

Make the game move smoothly at the table and on screen by replacing text-heavy craft and action information with strong visual shorthand, consistent symbols, compact labels, and quick-reference support.

The output should help players understand at a glance:

* what a card costs
* what category the cost belongs to
* what the craft does
* whether it is camp / field tool / zone use / recovery
* what action becomes available after crafting it
* what meter it affects
* what zone it belongs to
* what danger it protects against
* whether it creates a persistent engine or a one-time payoff

## Core Principle

Whenever possible:

* **show, do not explain**
* use icons, cubes, bars, tags, and compact labels
* reserve long text for tooltips, details panels, or rulebook reference
* the print version should be fast to parse from across the table
* the digital version should match the same visual language

# PHASE 2  DEFINE A UNIFIED VISUAL LANGUAGE

Create one consistent visual system used everywhere in the game.

## Build a unified icon/key system for:

* Wood
* Fiber
* Plant
* Stone
* Food
* Water
* Fuel / Fire / Hearth
* Shelter
* Tool
* Signal / Rescue
* Warmth
* Hunger
* Hydration
* Morale
* Hazard
* Camp craft
* Field tool
* Zone-use craft
* Recovery craft

## Rules for the visual language

* each material category should have a **simple icon** and a **color**
* each major meter should have a **bar symbol or meter badge** that visually resembles the player board bar
* each craft type should have a **frame treatment**, badge, or corner tag
* each zone should have a **zone icon**
* each danger type should have a **hazard icon**
* each persistent effect should have a visual indicator
* each one-time effect should have a different visual indicator
* each zone-use craft should clearly show:

  * where it is used
  * what action it enables
  * what success produces
* each protection effect should show what it blocks

Create a full visual key that could sit at the top of the print page and also be reused in digital UI.

# PHASE 3  REBUILD PRINT-SIDE QUICK REFERENCE

Redesign the print-side crafting tree and support pages to be readable at a glance.

## For every craft on the print tree:

replace text-first presentation with:

* craft name
* craft type badge
* color cubes or icons for cost
* prereq icon if needed
* result icons
* action unlock icons
* affected meter icons
* protection icons if relevant
* zone icon if it is a zone-use craft

## Examples of desired shorthand

* instead of writing “1 Wood + 1 Fiber” use colored cubes/icons
* instead of writing “+4 Hunger” use a Hunger bar symbol with +4
* instead of writing “Use in River to fish” use a River icon + fish action icon
* instead of writing “Protects against Bee Stings” use a hazard shield icon next to the Bee Sting icon

## Add or improve these print-side sections

* icon legend at top
* turn structure strip
* meter effect key
* zone-use action key
* craft type key
* hazard/protection key
* “what happens after you craft this” shorthand

Output a recommended print layout structure.

# IMPORTANT CONSTRAINTS

* Do not change the game’s core identity
* Do not rewrite balance unless clarity requires it
* Do not add visual clutter
* Prefer compact, reusable shorthand over decorative design
* Print and digital should share the same logic and visual language
* Every icon or shorthand must reduce friction, not add confusion

# DESIGN TARGET

The final result should make players able to look at a craft and instantly know:

* what it costs

* what danger it solves
